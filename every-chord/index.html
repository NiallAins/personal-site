Every Chord

Every Chord is an app for exploring musical chords and chord voicings for string instruments. Chords can either be generated from a scale, or input as text — a heuristics algorithm will then find the best fingerings available based on the specific instrument and tuning system provided.

Chord sheets can also be generated, saved, and printed off.

This project slowly evolved from several other algorithms and visualisations I had created while studying chords and music theory in general. I was also able to use my other project TinyTone to create WebAudio tones for playing each chord in the app. The codebase remains a Frankenstein mash up of these pieces, but stumbles along for now.
